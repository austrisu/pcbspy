PCBSpy

image layers · footprints · net tracing — help & workflow
← Back to PCBSpy

PCBSpy is a fully in-browser tool for reverse-engineering and documenting a PCB from photographs: stack board images as layers, align top/bottom scans, drop electrical annotations (pads, vias, holes), wire them into nets, and overlay KiCad footprints. Everything is local — nothing is uploaded; save/load a whole project as a .zip.

Getting around

  • Pan / zoom: the Pan tool drags the view; the mouse wheel zooms toward the cursor. Space+drag or middle-mouse pans in any tool. Fit frames the active layer.
  • Left rail = tools. Right panel = Layers, Annotate (by board side), and Nets. Drag the thin splitters between panels to resize them.
  • Undo / redo: Ctrl+Z / Ctrl+Shift+Z.

Layers

  • + Add Images to import board photos (you're asked for a name; the filename is the default). ▦ Add Footprint drops a simplified KiCad footprint as a layer.
  • Transform the active layer with Move / Scale / Rotate / Flip / Freeform (Freeform drags the 4 corners for perspective correction). It's non-destructive.
  • Per layer: opacity, a collapsible Adjustments block (brightness/contrast/saturation/hue/sharpen), reorder (▲/▼), show/hide (eye), rename (✎), lock (🔓/🔒 — a locked layer can't be transformed), and delete (✕).

Annotations & board side

Every annotation carries a side — Top, Bottom, or ⊕ through (both). Vias/holes default to through; everything else to top.

  • Dots: Via (green), Tag (yellow), Hole (blue, mechanical), Pad (silver square), Ground (black), Vcc (red).
  • Shapes: Rectangle (two clicks), Freeform quad (four clicks), Line/polyline (click points, double-click or Enter to finish, Esc cancels), Marker (click a point/rect to attach a label).
  • Tool options: click a tool to open its popover — set the Side, Size, Color, and (for electrical dots) a Net. The tool button shows the current side letter + colour.
  • Move a placed dot/marker by pressing on it. Right-click any annotation to change its Side / Size / Color / Net, or Delete it.
  • The Annotate panel groups items by side (TOP / BOTTOM / THROUGH) with a master eye per side and per-kind eyes; hiding a side/kind hides its marks (and their net overlay).

Nets (wiring)

  • Create a net in the Nets panel (name + Create), then right-click a via/tag/pad/hole to assign it — or set the Net in the tool popover before placing.
  • Wire with the Line tool: endpoints snap onto dots. Drawing a line from a net-assigned dot spreads that net onto the connected dot. Through vias bridge top and bottom; other dots only connect within their own side.
  • Guard rails: while drawing, hovering a dot that's on a different net or the other layer shows an error and the click is blocked — pick a compatible dot or Esc.
  • Color by net tints dots/traces by net. Hover a net in the list to highlight all its members on the board.
  • Holes are mechanical: they never auto-connect through lines, but can be given a net manually for reference.

Aligning top & bottom

⧉ Align layers opens a landmark wizard: pick a fixed Top and a moving Bottom layer, place 5–8 matching feature pairs (the active image is brought to the front for each side), then Compute a least-squares homography and Accept. The result co-registers both sides in the same world coordinates.

Saving

💾 Save writes the whole project (images stored verbatim, all layers/annotations/nets) to pcbspy_data_<timestamp>.zip. Open project… loads one back. Use a browser that supports the File System Access API (Chrome/Edge) for native dialogs, or it falls back to download + file-picker.
